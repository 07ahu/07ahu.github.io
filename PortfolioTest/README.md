# Portfolio mockup (static)

This folder contains a static HTML/CSS approximation of the Figma mockup you provided.

Files added:
- `portfolio.html` — static page implementing the layout
- `styles/portfolio.css` — styles used by the page

To view locally (macOS / zsh):

1) From the project root (`/Users/alaynahu/PortfolioTest`) run a simple HTTP server:

```bash
python3 -m http.server 3000
```

2) Open the page in your browser:

http://localhost:3000/portfolio.html

Notes:
- The page uses the images included in the repository (e.g. `name.png`, `character.png`, etc.) as placeholders.
- This is an approximation — if you want a pixel-perfect implementation or a React+Tailwind version, tell me and I'll scaffold it.
